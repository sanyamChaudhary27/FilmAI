# FilmAI - Video editing Agent

Welcome to **FilmAI**, a state-of-the-art Video Editing Agent built for the AMD Slingshot Hackathon.

## 🚀 Overview

FilmAI uses advanced AI agents to automate the video editing process. Just give it a description, and it will handle the cutting, transcriptions, and styling.

## 👥 Team

- **Sanyam**: Backend, AI Agents, Video Processing Logic.
- **Kanishka**: Frontend/UI/UX.

## 📁 Structure

- `agents/`: AI logic and task planning.
- `api/`: FastAPI server.
- `processors/`: Video and Audio editing engines.
- `core/`: Config and utilities.
- `frontend/`: React/Next.js application.

## 🛠️ Tech Stack

- FastAPI, FFmpeg, OpenAI Whisper, MediaPipe, React.

## 🚦 Getting Started

1. Clone the repo.
2. `pip install -r requirements.txt`
3. Set up `.env` with API keys.
4. `python main.py`
